# Экосистема Rule-ROM

Rule-ROM — не один монолитный продукт. Это реестр проектов с разными контрактами и разной границей открытости.

| Домен | Роль | Публичная граница |
| --- | --- | --- |
| [Liza](https://liza.rulerom.com/) | Liza — системный язык для переносимых вычислений с определённой семантикой и контролируемой стоимостью операций. | Проверяемое доверие независимо от автора |
| [Decima-8](https://decima.rulerom.com/ru/) | Нейроморфный runtime и формат `.d8p` | Физика v3, код, IDE, benchmark |
| [Philo](https://philo.rulerom.com/ru/) | Смысловой слой архитектуры | Пекарь, личность, память и детерминизм |
| [PKI](https://pki.rulerom.com/ru/) | Подписи и происхождение артефактов | Проверка авторства и целостности |
| [Audrey](https://audrey.rulerom.com/ru/) | Электроника и звук | Эксперименты и инженерные заметки |

## Принцип границ

- один проект — один домен и владелец контракта;
- воспроизводимые утверждения сопровождаются кодом, лентой, хешем или отчётом;
- исследовательский результат не объявляется производственным;
- открытая архитектура совместима с закрытым прикладным know-how;
- клиентские секреты и торговые ключи не являются частью реестра.
